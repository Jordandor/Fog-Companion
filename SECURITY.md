# Безопасность и конфиденциальность

Fog Companion не поднимает входящий сетевой сервер, не открывает порт для удалённого доступа, не внедряется в процесс Dead by Daylight и не читает память игры.

История матчей, профиль, настройки, координаты калибровки и диагностические журналы хранятся только в пользовательской папке Electron на локальном компьютере. Они не входят в репозиторий и не отправляются разработчику. Отчёты Electron о сбоях создаются локально с `uploadToServer: false`.

Для синхронизации приложение открывает официальный DBD Stats Tracker в изолированном постоянном разделе Electron. Токен Behaviour используется только внутри этого окна для запросов к официальному сервису и не сохраняется в `companion-data.json`.

Проверка обновлений обращается только к публичному API GitHub по HTTPS. В запрос не добавляются токены, cookies, профиль DBD, история матчей или другие пользовательские данные.

Не публикуйте содержимое `%APPDATA%\fog-companion`, диагностические журналы или дампы сбоев без предварительной проверки: они могут содержать локальные пути и технические сведения о системе.
